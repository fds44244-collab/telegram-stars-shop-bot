# Telegram Stars Shop Bot

Python Telegram shop bot built with aiogram 3.x, FSM, polling, and SQLite.

## Environment Variables

Set these on the hosting platform:

```text
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_user_id
```

Optional:

```text
DB_PATH=shop.sqlite3
CARD_NUMBER=4874070023914656
CARD_OWNER=Данило Р.
MANAGER_URL=https://t.me/ManagerFDSMARKETUA
REVIEWS_URL=https://t.me/FDSMARKETUA_reviews
```

## Start Command

```bash
python telegram_shop_bot.py
```
